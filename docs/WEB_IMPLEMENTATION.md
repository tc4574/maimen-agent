# McBot 网页实施与验收

2026-10-23。实现入口：`web/index.html`，启动：`scripts/start-web.ps1`，真实推荐开关：`-Live`。本轮没有调用真实MCP，未创建订单。

## 框架与视觉

单一角色空间；问答和推荐按需展开；详情、收藏、历史、偏好共用原生dialog，避免多层弹窗。桌面左导航，手机底部导航与底部抽屉。沿用用户已有McBot动画，保留原始素材与许可证。

颜色：明黄 #FFC72C、品牌红 #DA291C、正文 #24211D、纸白 #FFFEFB、辅助灰 #777268。中文短标题使用ZCOOL KuaiLe并回退楷体；正文与数字用系统字体。角色是主视觉，功能图标统一线条风格，商品卡内图标仅用于装饰。

为减少依赖，本轮将此前React/Vite建议调整为原生HTML、CSS、ES modules；FastAPI同源提供网页和API。只有角色库作为本地第三方资源，无前端构建步骤。状态、渲染、网络和语音函数集中在一个小型应用模块，后续规模扩大时再拆分。

## 实际完成与边界

- 首页、响应式导航、抽屉、文字入口、偏好表单、推荐请求、详情、报价到期提示、选卡与撤回、本机收藏和聊天记录。
- 语音API能力检测、识别、播报、退出和切后台停止；未做真实麦克风/手机浏览器验收。
- 推荐使用现有六项真实查询后端。当前预览服务未开启live；启动脚本加-Live才启用。取消等待丢弃旧响应，不宣称取消服务器全部调用。
- 商品保留沿用keep_codes，不能称为槽位锁定；收藏复用重新找商品，不保证原规格复原。无单品替换、通用自由对话、活动问答和订单接口。
- 本机存储不保存原始音频或MCP Token；收藏和对话支持清理。非多账号公共网站。
- 移动网页不是微信原生小程序，微信WebView语音兼容性尚待实测。
