# McBot 网页

原生 HTML/CSS/ES modules，无构建依赖。页面由 FastAPI 同源服务，MCP 凭据不进入前端。

在项目根目录运行 `scripts/start-web.ps1`，然后访问 http://127.0.0.1:8000 。脚本默认开启真实只读 MCP；`-Offline` 关闭外部查询。

已实现：用户原有 GrokBall McBot、响应式角色主页、导航与底部抽屉、文字入口、Web Speech 识别和播报、结构化偏好、真实推荐、活动/门店/菜单/营养/优惠浏览、餐单详情、保留商品重抽、选择与撤回、本机收藏和对话记录。对话使用本机 DeepSeek，模型只能调用查询、推荐和选卡。

尚未提供套餐槽位直接替换、自动持卡核实和真实订单。收藏后的再次推荐按商品代码查找，不保证原套餐规格完全恢复。

按移动网页/小程序常见交互组织：44px触控、安全区、底部导航、单层抽屉、动态视口与键盘适配；这是移动网页，不是已打包的微信原生小程序。语音必须在目标手机浏览器实测，微信内嵌浏览器可能不支持。
